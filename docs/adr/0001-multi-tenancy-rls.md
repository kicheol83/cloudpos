# 0001. 멀티테넌시: 공유 스키마 + RLS

## 배경

테넌트(매장 운영사)가 많아져도 마이그레이션과 커넥션 관리가 단순해야 한다.

## 결정

- 모든 테넌트 테이블에 `tenant_id`를 두고, PK와 인덱스의 첫 번째 컬럼으로 쓴다.
- 모든 테넌트 테이블에 RLS(`FORCE`)를 켠다. 트랜잭션 안에서 `SET LOCAL app.tenant_id`를 설정한다.
- 다른 테넌트로 조회하면 0건이 나오는지 테스트로 확인한다.

## 검토한 대안

- 테넌트별 스키마: 테넌트 수만큼 마이그레이션을 돌려야 한다.
- 테넌트별 DB: 커넥션과 운영 비용이 테넌트 수에 비례한다.
- RLS 없이 `WHERE tenant_id`만 사용: 조건 하나를 빠뜨리면 바로 데이터 유출이다.
