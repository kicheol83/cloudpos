# 0003. 인증 단위는 디바이스 + 직원 PIN

## 배경

POS 직원은 공용 태블릿에서 하루에도 여러 번 로그인한다. 비밀번호는 현실적이지 않고, 4자리 PIN만으로는 안전하지 않다.

## 결정

- 매니저가 디바이스를 등록하고 한 번 페어링한다. 디바이스 시크릿은 한 번만 반환하고 DB에는 SHA-256 해시만 저장한다.
- 로그인은 `device_id` + `device_secret` + `staff_id` + `pin`.
- PIN은 Argon2id로 해시한다. 5회 실패하면 15분 잠금.
- 로그인 시 테넌트는 요청 본문이 아니라 `device_directory`에서 찾는다.
- Access token은 RS256 JWT(15분), gateway는 JWKS로 검증만 한다.
- 리프레시 토큰은 매번 교체하고, 이미 쓴 토큰이 오면 패밀리 전체를 폐기한다.

## 결과

- 디바이스를 폐기하면 그 디바이스의 세션이 모두 끊긴다.
- 권한이 필요한 작업은 매니저 PIN으로 2분짜리 승인 토큰을 따로 발급한다.
